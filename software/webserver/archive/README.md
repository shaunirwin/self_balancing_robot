# Earlier control interfaces

These files are retained for reference. The supported laptop dashboard is in
`../index.html` and is run with Vite as described in `../README.md`.

- `client.html` is an early browser control page. It uses a fixed robot address
  and an older request format.
- `gui.py` is an earlier Tkinter control client.
- `server.py` is a standalone Python HTTP server experiment.

These files are not part of the current dashboard build or setup instructions.
